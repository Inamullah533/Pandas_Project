# 🌍 Countries Data Analysis

## 📌 About the Project

This is my **Data Analysis Capstone Project** based on **countries around the world**.

I developed this project using **Python and Jupyter Notebook**. The main purpose of the project is to explore, clean, and analyze country-related data and extract **meaningful insights** from the dataset.
